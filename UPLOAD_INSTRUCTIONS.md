# Publish your GitHub profile

1. Open or create the public repository named `NextIn035846` (the name must exactly match your GitHub username).
2. Extract this ZIP locally. Upload `README.md` and the complete `assets/` folder (including `profile-showcase.png`) to the repository root; do not upload only the ZIP.
3. Commit to the default branch.
4. Visit https://github.com/NextIn035846 and review the profile on desktop and mobile.
5. Open `preview.html` locally to inspect the assets before publishing.

## Before you publish
- The profile showcase uses your professional photo appearance in a business-focused portfolio layout. Review the image at full size to ensure the text remains legible for your audience.
- GitHub may display animated SVGs as static images in some contexts; readable base states are included.
- The resume supports the role history and project descriptions in the README. Exact project repository URLs and performance metrics were not provided, so they are not fabricated. Add links once you confirm the public URLs.
- The SVGs contain embedded PNGs and do not fetch external assets. Fonts use system fallbacks, avoiding remote font requests.
